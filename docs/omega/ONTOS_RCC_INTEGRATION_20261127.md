# ONTOS RCC — signed reversible memory (2026-11-27)

Base main d015a48ddce880112afd378a058a44474182eb4a. New RCCJournal integrates bounded R0 atom projection and exact R1 additive contributions with the existing native ManagedJournal. Independently pinned Plan binds tenant, fixed encoder SHA256, epoch, dimension (1..8), separate Ed25519 writer/revoker public keys. Canonical JCS body, domain-separated signatures and chained event heads. Strict role verification on append/replay. Compaction retains the full bounded transcript; exact retained Fence required for all public read methods. Rejected or stale writes return no successor fence or private state. Independent trust in the anchor is required for explicit recovery; recovery alone is not a freshness proof.

Atom schema: bounded identifier, key, string value, valid interval, source commitment, parents, evidence classification. Sequence supplies transaction time; latest surviving observed version is selected for valid/known query. Current revocation overlay applies even to historical queries. Observed is a signed assertion, not proof of factual truth. Inferred, simulated and disputed records cannot enter the active observed view or active R1 lineage; observed derived atoms require eligible parents. Verified classification deliberately unsupported pending independent verification. R1 requires explicit eligible parents; samples are bounded integer vectors with labels. Replay computes A=sum xx^T, b=sum xy, and exact Fraction ridge weights; revoke deducts affected active samples once using insertion-topological closure; separately recomputes active-set aggregate and checks equality. No hidden encoder retraining. New atom/contribution nodes limited to 16, total operations to 32, reserving at least one revocation per admitted node. No reset at compaction. At most 8 parents; body <=2048 bytes. No R2/R3/R4 execution, no complete Capsule IR or 8-dimensional OTCE. No live authorization lease, authenticated read RPC, encrypted storage, physical erasure, full model unlearning or LLM adapter promotion. Old commands retain plaintext inside journal; logical revocation is not deletion from storage. Trusted local orchestrator must authenticate callers, enforce access policy and independently retain latest fence; compromised anchor plus retained fence can defeat freshness. Current implementation replays bounded history on reads/writes, not an incremental-performance claim. No operational grants.
