## Formal semantics and kernel

Validated AST is restricted to x/y, finite literals of magnitude <=1e6, +/-/*//, unary +/- and abs/min/max, <=100 expression nodes, depth <=14, source <=2048 characters. Domain: binary64 input pair in [0,1]^2, ordinary CPython IEEE-754 round-to-nearest semantics. Formal safety means every allowed operation is defined, every intermediate result is finite and its magnitude <=1e12, and every division has a nonzero denominator. Syntax restrictions prevent candidate imports, dynamic calls, assignments, I/O, arbitrary host code, or changes to the audit kernel. No external solver or GPU is required for this proof.

`prove` first generates a typed path-indexed specification. Interval producer outward-rounds arithmetic and recursively bisects failing boxes (alternating axes, depth <=8, <=256 leaves); each successful box must discharge exactly the generated obligations, with a deterministic transcript digest. A second interpreter in `interval_checker.py` reconstructs the complete domain cover using `Fraction` endpoints and separately rounded bounds; independently rejects poles, overflows and falsely narrowed learned bounds. Both numerical checks are mandatory. Conservative overapproximation can reject safe programs. Unproved/unknown is rejected, never equivalent to unsafe counterexample or a successful proof. This is not proof of full behavior for all host environments.

The CTL checker supports Boolean atoms/connectives, AX/EX, AG/EG, AF/EF, AU/EU, with least/greatest fixed points. It checks candidate-specific finite admission graphs: `AG(evaluating -> checked obligations and proof)` and `AG(admitted -> checked obligations, proof, empirical, performance, audit)`. A bypass negative control falsifies both guards. This is a proof on the explicit protocol model, not a formally verified refinement of all Python runtime code. The normal K prover recursively saturates a negated general formula in NNF, branches on disjunctions, propagates all boxes and creates a successor per diamond. Closed tableau establishes validity on arbitrary Kripke frames; open tableau yields a checked countermodel, including legitimate dead ends. Exhausted resources yield unknown. It independently proves the candidate-specific modal inference from proof premises to admitted safety; validity of logical inference does not itself establish the numerical premises. Limits: 512 worlds per model, 1024 formula nodes, depth 32, K 8192 tableau nodes/256 recursion-depth cap. Bounded software checks are performed during candidate processing, not hard real-time deadline guarantees. Certificate includes typed specification, explicit CTL/K formulas, check results and digests, independent numerical confirmation and derived rules; `verify` regenerates and compares canonical JSON from trusted code. The exact-rational numerical checker is distinct from generator; CTL/K proof logs are checked by deterministic recomputation, not a proof assistant external to this project.

## Runtime and dynamic knowledge

`Cascade.evaluate` always runs proof before `Expression.evaluate`, including every regular worker process, cluster actor and swarm evaluator. Stage 1 is now formal totality, not the old three-point smoke. The opt-in cluster `formal_safety` flag is retained for compatibility to select **full trace retention**, not to disable the proof. Core admission independently recomputes safety before the optional v21 latency profiler, preventing a forged Stage 3 response from injecting an unsafe expression. The audit token binds formal proof and prior matching theorem references to exactly the proposed source, session/nonce and metrics. Source integrity hashes protect against on-disk changes after kernel initialization under trusted installation/operator assumptions. HMAC is not a hardware trust anchor, and arbitrary malicious host code is out of scope. The existing coordinator validates admitted cluster results and rulebook transitions before CAS. The audit cannot sign an expression with a failed proof.

New proved rules contain exact normalized subtree, full domain, lower/upper bounds, predicate kind and content hash. For example, after `1/(.25+x)` has been certified, the rule `nonzero(.25+x)` is identified inside `2/(.25+x)`. Matches add verified proof references, not untrusted assumptions; the second numerical proof still runs for the new expression. A source entry is admitted only after verified matching certificate. Duplicate entries are idempotent, existing rules cannot be replaced, forged records fail closed. Each archive retains a bounded monotone working set of 32 distinct proved sources, including seed, with deduplicated rule IDs; once full no more entries are stored in that set, and new candidates still require independent full proof. The broader accepted lineage remains available for proof replay. This capacity is an engineering choice for bounded authenticated snapshots, not an unlimited theorem store. v33 modular u16 discoveries are separate typed mathematical evidence; they are not accepted as binary64 safety axioms, since modular equalities do not imply floating-point equality. No rule can weaken the trusted kernel, replace authorization, or grant itself validity.
