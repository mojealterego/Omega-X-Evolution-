Base main 724c1ad7a3e79a723e82dc3a9666762d1ad99c2d. Shared v37 simulator generator and fixed finite model policy. Existing replay remains compatible. No arbitrary callback, real tool execution, memory promotion, policy self-modification, changes to evaluator, or operational privileges. Same process is a logical boundary, not a sandbox.

The controller sees exactly three fields: discrete reading, six-dimensional continuous reading, damage. No epoch, true regime, state, OOD flag, tamper/lure flag, reward, score, seed or clock is passed into decide. Scorer records are returned only when the simulated episode terminates. Model uses all three known signature priors, known simulator noise and state transition laws, a fixed regime hazard .03, uniform initial joint state, and existing v50 filter with floor .004 over 12 states. The contamination mixture is evaluated in log space using actual observations; action maximizes posterior probability of model success, with abstention on contamination probability >.5 or maximum success <.5. These are engineering choices, not an empirical learned model, full EFE, native Titans or holdout validation. No active sensor repair or metabolic survival mechanism in this existing simulator. Zero harm results from never issuing the simulated lure action 4, not a proof of general immunity.
