The `VirtualCluster` is separate from `KubernetesProvider` and deliberately never performs network writes or purchases. No production SDK is replaced with a fake module. The reference comparisons execute real application code and actual solver/training work. Any unsupported source string, resource contract or collective mismatch fails closed. No model result is reported as native kernel or production hardware verification.

Commands, source hashes, test outputs and environment are preserved in `verification-v361.txt`. The historical v36.0 results remain unchanged. For the new numerical tests, Torch runs on CPU with one thread; mixed platform arithmetic is judged by explicit tolerances, not bitwise identity.
