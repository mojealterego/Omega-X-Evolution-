## 5. QUBO and numerical constraints

`BinaryProblem` compiles an integer objective plus squared integer equality penalties. Penalty exceeds the objective range; slack encodes bounded capacities. All external vectors are validated and scored locally; invalid or infeasible samples cannot enter the feasible best. Logistic workload supports up to eight jobs/devices subject to a 64-variable cap; objective is sum of device runtimes, not makespan or network cost. Sparse tensor selection uses supplied atoms, quantized squared reconstruction error and fixed cardinality, up to 32 atoms and 4096 elements. Exact search is capped at 65536 primary assignments; larger instances use deterministic simulated annealing with categorical/cardinality-preserving moves and recomputed slack. Exhaustive failure alone proves infeasibility. D-Wave adapter requires explicit authorization; deterministic exact sampler checks the QUBO transport/solution contract but is not quantum dynamics or speedup. Benchmark: allocation cost 5, exact; tensor residual 0, selected atoms 0 and 1; another 18-primary-bit assignment test uses non-exhaustive categorical moves.

## 6. Memory synthesis

`SynthesizedIndex` derives token-to-document hyperedges from an authenticated GraphMemory snapshot; no fabricated edges are stored as facts. `Plan` is a typed expression tree with bounded lexical/associative/hypergraph leaves and recursive propagation, square, min-free additive/multiplicative/max compositions. Search generates new tree structures, ranks on training, challenges baseline on validation, reports both once on held-out queries. Bounded search (128 plans, 20 million work units) and provenance accompany retrieved evidence. Benchmark (three documents, separate query texts) searched 24 plans, selected graph propagation over lexical score; MRR 0.5 vs 0, hypergraph eight edges. This small fixture does not establish broad generalization or invent new primitive operators.

Each receiving peer performs its own formal and empirical qualification; input code is interpreted only. Three real loopback peers demonstrate discovery through another peer and delivery of a verified artifact to a newly discovered node. Limits include 33 advertisements and 128 sends per ledger. No dynamic loading or rewriting host code.

## 9–10. Proof and consensus

Native QF_BV Z3 proves equality over all 2^32 u16 input pairs or returns SAT/unknown. Ring proofs remain independently constructive. Mixed arithmetic/bitwise identity `(x AND y)+(x XOR y) = x OR y` is checked across the full domain. Extensional Lean code uses `funext` and `bv_decide`; require_lean rejects unavailable/failing toolchain; no Isabelle adapter execution claimed. Neither arbitrary HOL nor compiler equivalence is inferred. BFT uses authenticated validators and n-f quorum with n>=3f+1, signed rounds, persisted locks, prior prevote certificate for conflicting value transitions, independent block replay and committed membership changes restricted to genesis-eligible identities. Task lease expiry is in committed heights; attempts and aggregate budget charged before work. Signed results reconstructed by all recipients; stale workers cannot complete reassigned tasks. Three-of-four network round after leader failure, catchup of absent peer, lock preservation across rounds, reconfiguration and stale-result rejection are tested. Bounds: 16 validators, 32 eligible, 128 heights, 32 rounds, 64 tasks, 256 assignments. Caller advances round and invokes `run_round`; no automatic pacemaker, no unconditional liveness, disk rollback protection or general BFT proof. Single-host tests do not establish geographic-network throughput. Quorum assumes <=f Byzantine validators at each committed membership and protected signing keys/state.

## 11. Scientific discovery and online plasticity

Polynomial identities over Q/R use an exact rational determining grid (degree+1 distinct coordinates per axis) and a separate coefficient expansion checker; counterexamples are exact. 128 grammar conjectures: 98 proved, 30 refuted. Finite grid is a theorem for the restricted polynomial language, not experimental validation for arbitrary functions. Dimensioned Laurent monomials permit negative exponents; nonzero inputs, train/validation selection, test once. Synthetic inverse-square data recovers mass/radius^2 with test RMSE ~1.98e-16. This rediscovers a known relationship, not a new law of nature.

`llm_plasticity.Session` freezes base parameters, wraps q_proj/v_proj in trainable A/B adapters, uses Torch autograd AdamW with finite checks, gradient clipping, fixed operator action tokens; local safetensors-only Transformers adapter, no remote model code. Model cap 4B parameters, 512 tokens, 1M adapter parameters; explicit device and CUDA free-memory check. OnlineCampaign consumes independently replayed v25 trajectories; rounds sample within current qualified parent set, charge work durably, fit adapter and use promoted weights on following rounds. No change to formal gate. Candidate validation must strictly improve and retention must not exceed prior/frozen MSE +0.002. Two-round genuine tiny CPU decoder experiment: 8 proposals, 8 gradient steps, 192 trainable/27574 frozen weights, restart identical; both candidates rejected, held-out MSE unchanged at 0.03309536. Negative result intentionally retained. Full model/CUDA absent; actual large-model generalization and mid-batch updates are open. Training is an explicitly authorized bounded campaign; interrupts consume reserved budget and require recovery. Source-bound checkpoints intentionally isolate incompatible versions.
