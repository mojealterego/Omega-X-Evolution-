## Source evidence and review findings

The PDF reports 234.4/240 survival steps, 92.9% accuracy, 93.0% return-regime recall, 4.5-step adaptation, zero harm events and 3.907 correct steps/nJ for its full L7 simulator. These are Argon/source-reported figures, not newly reproduced repository results. The no-living-memory ablation reports 240.0 survival steps and 71.7% recall; preserve both objectives.

- pp. 27–35: episode uses inline approximations and does not call all defined classes end-to-end. Ground-truth regime enters calibration/empowerment; the displayed empowerment term is constant across proposed actions. Verify observation-only decision paths and action-conditioned quantities.
- pp. 26, 30–34: tamper blocking follows configuration flags; HMAC state in one Python object does not establish process isolation. Do not infer live security guarantees from simulated counters.
- p. 26: flooring e-wealth changes the multiplicative process, so quoted Ville thresholds need an independently valid statistical model under a specified null.
- pp. 25–26: transaction timestamps are stored but query filters only valid time; require true two-axis visibility tests.
- p. 22: do not import general string sympification for untrusted input; existing restricted parser and independent verifier retained.
- pp. 19, 35: greedy pair merging is a heuristic; causal matrices built from aggregate accuracy do not independently demonstrate interventional emergence.
- pp. 29–38: operation/energy costs are modeled, not measured hardware power; accuracy excludes abstentions. Report coverage and both conditional/unconditional accuracy. Baselines are synthetic proxies, not actual DGM/AlphaEvolve/ShinkaEvolve executions. Shared seeds require paired analysis and appropriate multiple-testing handling.
