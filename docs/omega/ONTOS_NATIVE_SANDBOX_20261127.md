RLIMIT_AS is address space rather than measured resident memory, not a cgroup. Deadline bounds packet exchange and normal exit, not an OS stall in spawn/kill; cleanup can add two seconds. Only Linux x86_64 verified; no Android ARM64 support. Requires procfs and libseccomp.so.2. This is native confinement of reference controller, not physical production deployment, adversarial code admission or full system sandbox certification.
